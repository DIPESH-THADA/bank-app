An unofficial student banking project

This website is an independent software-development portfolio project by Dipesh Thada. It is not affiliated with, endorsed by, or operated by Rastriya Banijya Bank.

The bank name is referenced as part of a UI study. This site provides no real banking services, opens no real bank accounts, issues no payment cards and moves no real money.

Use the Try demo account button to explore. If you register, use fictitious details and a password created only for this demonstration. Never enter real banking credentials, PINs, card numbers or other sensitive information.

Demo registrations, optional profile details and uploaded photos are stored by this student project on Netlify. They are not sent to a real bank. Email verification is simulated and no verification email is sent.
